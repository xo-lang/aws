# v0.3.0

The AWS SDK for Xo with credential discovery, configuration and file
uploads in modules of their own: the core module
(`github.com/xo-lang/aws`), `credentials`, `config`, `fileio` and all
436 service modules, 440 in all, tagged v0.3.0 at one commit. Requires
Xo 0.51.0 or later.

A community SDK for the Xo language. Not affiliated with or endorsed by
Amazon. Amazon Web Services and AWS are trademarks of Amazon.com, Inc.
or its affiliates.

## Why

Up to v0.2.1 the core module's `xo.lock` effects line was `clock, env,
fs, net.dial, proc, rand`, so a program that called S3 with keys it
held accepted reading the environment and files and running programs.
Now the core and every service reach only `clock`, `net.dial` and
`rand`; the modules that discover credentials, read configuration or
read files show their wider sets by name
([decision 0011](../decisions/0011-credential-modules.md)).

## Upgrading from v0.2

Import paths do not change. What changes:

- **You use `config.load_default_config` or `credentials`**: add the
  requires, and your program builds as before.

      xo get github.com/xo-lang/aws/config@v0.3.0 github.com/xo-lang/aws/credentials@v0.3.0

- **You start the credential tasks**: they are functions of `config`
  now, taking the configuration first.

      // v0.2
      cfg.watch_token_files(os.tasks, os.fs, os.clock)
      cfg.run_credential_processes(os.tasks, os.proc, os.clock)
      // v0.3.0
      config.watch_token_files(cfg, os.tasks, os.fs, os.clock)
      config.run_credential_processes(cfg, os.tasks, os.proc, os.clock)

- **You upload a file by path** (`aws.upload_file`): add the `fileio`
  require and import; the call is the same with `fileio.`.

      xo get github.com/xo-lang/aws/fileio@v0.3.0

      use github.com/xo-lang/aws/fileio
      let up = fileio.upload_file(os.tasks, os.fs, "backup.tar")?

- **You upload from your own reader and want retries**: use
  `aws.upload_opener`, which asks your function for a fresh reader on
  each attempt (`done` runs when the operation returns). A reader that
  can be read once stays `aws.upload_reader`.

      let up = aws.upload_opener(fn() -> http.BodyReader ! Str { Ok(make_reader()) }, length: Some(size))

- **You hold your own keys**: `aws.static_provider(id, secret)`, in the
  core; `credentials.static_provider` still works and forwards to it.
- **You used `credentials.SessionCache`, `aws.load_token_file` or
  `TokenFile.watch` directly**: `aws.SessionCache`,
  `credentials.load_token_file`, `credentials.watch(t, fs, clock)`.

## Install

    xo get github.com/xo-lang/aws@v0.3.0 github.com/xo-lang/aws/service/s3@v0.3.0
